# Requisitos

## Objetivo

Criar um CRM pequeno para captar solicitacoes de orcamento de servicos de ar-condicionado e permitir que o profissional gerencie esses leads.

## Escopo do MVP

- Landing page publica.
- Formulario de solicitacao de orcamento.
- API REST para criacao e gestao de leads.
- Login administrativo.
- Dashboard com contadores por status.
- Lista de leads com busca e filtro.
- Detalhes do lead com status, observacoes internas e link para WhatsApp.
- Protecao simples anti-spam.

## Fora do MVP

- Upload de fotos.
- PDF de orcamento.
- Agenda.
- Financeiro.
- Kanban.
- Multiusuario com permissoes.
- Integracao oficial do WhatsApp.
